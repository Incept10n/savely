### API Reference

#### POST `/predict` — Предсказание категории
Определяет категорию слова через эмбеддинги. Если сходство < 40%, возвращает `"Другое"`.

**Запрос (JSON):**
```json
{
  "word": "смартфон" // string с минимальной длиной 1, инпут покупки, обязателен
}
```

**Ответ (200 OK):**
```json
{
  "category": "Электроника", // string, предсказанная категория
  "confidence": 87.45         // float, уверенность модели в %
}
```

### API Reference

#### POST `/predict` — Предсказание категории
Определяет категорию текста (например, комментария к покупке) на основе семантического сходства через эмбеддинги. Если максимальное сходство с базой составляет менее 40%, автоматически возвращается категория `"Другое"`.

* **Запрос (JSON):**
  ```json
  {
    "word": "купил смартфон" 
  }
  ```
  *Параметры запроса:*
  * `word` (string, обязательный): Текст инпута покупки (минимальная длина — 1 символ). Перед обработкой автоматически очищается от пробелов и приводится к нижнему регистру.

* **Ответ (200 OK):**
  ```json
  {
    "category": "Электроника", 
    "confidence": 87.45         
  }
  ```
  *Параметры ответа:*
  * `category` (string): Предсказанная категория из вашей векторной базы данных.
  * `confidence` (float): Уверенность модели в процентах (нормализованное расстояние сходства).

* **Возможные ошибки:**
  * `503 Service Unavailable` — Возвращается, если векторная база данных еще находится в процессе первоначальной инициализации (холодного старта) и память приложения пуста.

#### POST `/reload_data` — Обновление векторной базы
Запускает процесс ручного или автоматического перестроения векторного пространства в оперативной памяти (RAM) приложения. 

* **Особенности работы:** Ручка работает асинхронно. FastAPI мгновенно возвращает JSON-ответ, не блокируя клиента, в то время как тяжелый фоновый воркер уходит скачивать новый файл из S3, генерировать эмбеддинги через Hugging Face и обновлять данные в памяти.
* **Запрос:** Не требует тела запроса (Empty Body).
* **Ответ (200 OK):**
  ```json
  {
    "status": "Процесс обновления векторной базы успешно запущен в фоновом режиме."
  }
  ```

### Переменные окружения (Environment Variables)

Для корректной работы сервиса и его интеграции с S3-хранилищем (SeaweedFS) и MLflow необходимо настроить следующие переменные окружения (например, в файле `.env` или секции `environment` вашего `docker-compose.yml`):

| Переменная | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `MODEL_NAME` | `intfloat/multilingual-e5-small` | Название предобученной модели Hugging Face для генерации эмбеддингов. |
| `S3_BUCKET` | *Обязательное* | Имя бакета в S3-совместимом хранилище, где лежит CSV-файл с обучающей выборкой. |
| `S3_CSV_KEY` | *Обязательное* | Путь к CSV-файлу внутри бакета (например, `data/dataset.csv`). |
| `S3_ENDPOINT_URL` | *Обязательное* | URL-адрес для подключения к вашему S3-хранилищу (например, `http://seaweedfs:8333` для SeaweedFS). |
| `AWS_ACCESS_KEY_ID` | *Обязательное* | Идентификатор ключа доступа (Access Key) для авторизации в S3/SeaweedFS. |
| `AWS_SECRET_ACCESS_KEY` | *Обязательное* | Секретный ключ (Secret Key) для авторизации в S3/SeaweedFS. |
| `AWS_DEFAULT_REGION` | `us-east-1` | Регион AWS (для локальных S3-хранилищ вроде SeaweedFS обычно оставляется дефолтным). |
| `MLFLOW_TRACKING_URI` | `http://mlflow-server:5000` | URL-адрес сервера MLflow для логирования метрик, параметров и версионирования датасетов. |
| `GIT_PYTHON_REFRESH` | `quiet` | Управляет поведением Git-интеграции в MLflow. Значение `quiet` отключает спам-ворнинги об отсутствии Git в Docker-контейнере. |
| `HF_HUB_DISABLE_SYMLINKS_WARNING` | `true` | Системная переменная Hugging Face, отключающая предупреждения о создании символических ссылок при кэшировании моделей. |


### Требования со стороны бекенда

Предлагаю делать каждый месяц cron job по выгрузке имеющегося датасета. Для корректной работы с сервисом классификатора нужно сохранять новый файл на S3 bucket, под названием `savely_spends.csv`!!! 
После чего по ручке /reload_data можно будет перейти на новый датасет.
